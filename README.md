## 🎯 Что это

У вас есть VPS или домашний сервер, но нет желания разбираться в Linux. FoxLair делает всю работу за вас:

| | |
|---|---|
| 🔌 **Подключается по SSH** | Проверяет отпечаток сервера, права, место, память, носитель системы |
| 🦊 **Ставит агента** | Небольшую службу, которая выполняет только команды приложения и не открывает портов наружу |
| 🔑 **Забывает пароль** | После установки заходит по ключу вашего компьютера — пароль сервера больше не нужен |
| 🛡 **Защищает сервер** | Вход по ключу, фаервол, fail2ban, автообновления — каждая часть по отдельности |
| 🧩 **Ставит модули** | Docker, Caddy, VPN, DNS, хранилище файлов, игровые серверы, умный дом — одним нажатием |
| 📊 **Показывает дашборд** | Нагрузка, память, диск, службы и состояние модулей — без терминала |
| 🖥 **Даёт консоль** | Когда всё же нужна командная строка, она есть прямо на странице сервера — вместе с журналами служб |
| 🧭 **Живёт в трее** | На компьютере крестик окна сворачивает FoxLair в трей, а запуск при входе в систему включается на первом шаге |
| 📱 **Работает везде** | Windows, Android и Linux: поставить агента и управлять сервером с компьютера или из дороги |

Каждый шаг объясняет лис-проводник **Тейл**: что произойдёт, чем это полезно и чем рискованно.
Ничего не меняется без вашего подтверждения.

## ⚙️ Как устроено

```mermaid
flowchart LR
    U["🧑‍💻 Вы"] --> A["🦊 FoxLair<br/>приложение"]
    A -- "1. SSH и отпечаток сервера" --> S["🖥️ Ваш сервер"]
    A -- "2. Агент + проверка SHA-256" --> S
    S --> G["🤖 foxlair-agent<br/>слушает только 127.0.0.1"]
    A -- "3. SSH-туннель" --> G
    G -- "4. Страница настройки и дашборд" --> A
    G --> H["🔐 foxlair-helper<br/>root, только действия модулей"]
    H --> M1["🛡 Защита сервера"]
    H --> M2["🐳 Docker · 🌐 Caddy · 🔒 VPN"]
```

- **Наружу ничего не открывается.** Агент слушает только сам сервер, приложение приходит по SSH-туннелю.
- **Пароль нужен один раз.** Дальше вход по ключу вашего компьютера, который хранится в хранилище паролей системы.
- **Систему меняет только помощник** и только теми действиями, что описаны в модулях. Единственное
  исключение — консоль сервера: вы сами её просили, и она делает ровно то же, что ваш вход по SSH.
- **Агент приезжает с сайта**, а не лежит внутри установщика: подписанный манифест, сверка SHA-256
  и подписи — и приложением, и самим агентом.
- **Настройка переживает перезагрузку.** Каждый шаг пишется в журнал: незавершённый повторится, выполненный — пропустится.

### Установка

1. Скачайте файл для своей системы из таблицы выше.
2. Запустите и выберите язык, палитру и тему.
3. Введите адрес сервера, логин и пароль, которые прислал хостинг.
4. Подтвердите отпечаток сервера и дождитесь установки агента — дальше всё происходит на странице сервера.

**Что нужно от сервера:** Ubuntu 22.04 или 24.04 LTS, x86_64 или ARM64, от 512 МБ памяти и 2 ГБ свободного места.
Интернет во время установки нужен вашему устройству, а не серверу: агента скачивает приложение и передаёт по SSH.
Подойдёт любой VPS, домашний компьютер или Raspberry Pi (лучше не с SD-карты — приложение предупредит).

**Обновления.** На Windows и Android приложение 0.2.25 и новее предлагает обновиться само. На Linux новую версию
ставят пакетом. Агент на сервере обновляется сам — страница сервера предложит обновиться.

<details>
<summary><b>Linux: что нужно системе</b></summary>

<br>

- glibc 2.34 или новее и WebKitGTK 4.1.
- `.deb` и `.rpm` ставьте через `apt` или `dnf` — зависимости подтянутся сами.
- `.AppImage` достаточно сделать исполняемым: `chmod +x FoxLair-0.3.1-linux-x86_64.AppImage`.
- Приложение на Linux не обновляется само: новую версию ставят пакетом поверх.
- Трей — системное меню с теми же пунктами, что панель на Windows.

</details>

> [!NOTE]
> Приложение пока не подписано сертификатом удостоверяющего центра, поэтому Windows покажет предупреждение SmartScreen:
> «Подробнее» → «Выполнить в любом случае». APK подписаны ключом выпуска (схемы v2 и v3) и ставятся поверх прежних версий.
> Обновления агента подписаны ключом проекта и проверяются перед установкой.

## 🛡 Безопасность

- Отпечаток ключа сервера показывается при первом подключении и сверяется при каждом следующем.
- Пароль сервера не сохраняется: он нужен только для установки агента.
- Ключ вашего компьютера и токены доступа лежат в хранилище паролей операционной системы, а не в файлах приложения.
- API агента закрыт токеном, доступен только с самого сервера и проверяет заголовок `Host` — страница из интернета до него не достучится.
- Страница сервера открывается по одноразовому коду, который живёт полминуты и сгорает при первом входе.
- У каждого вашего компьютера свой токен: вернуться с другого по паролю сервера можно, не отбирая доступ у прежних.
- Обновления агента скачиваются по HTTPS, сверяются по SHA-256 и подписи Ed25519; ставит их привилегированная служба, а не сам агент.
- Шаг «Вход только по ключу» не отключит пароль, пока не убедится, что вход по ключу работает.
- Защита собирается по частям: по каждой — вход, фаервол, fail2ban, обновления — вы решаете сами,
  и отказ от части не просто пропускает её, а возвращает сервер к тому, что было до неё.

Нашли уязвимость? Напишите через [приватный отчёт GitHub](https://github.com/DiFoxenGit/foxlair/security/advisories/new) — см. [SECURITY.md](SECURITY.md).

## ❓ Частые вопросы

<details>
<summary><b>Куда делись стили «Графит», «Стекло» и «Терминал»?</b></summary>

<br>

В 0.3.0 их заменили палитры Fox Brand — общего оформления всех приложений DiFoxen. Прежний стиль переносится
сам: он становится палитрой Toffee, а тема и язык остаются прежними. Другую палитру можно выбрать в настройках
в любой момент.

</details>

<details>
<summary><b>Что будет с тем, что уже стоит на сервере?</b></summary>

<br>

Перед установкой FoxLair читает сервер и показывает, что нашёл. Перед каждым изменением показывает план
и ждёт подтверждения. Модуль «Caddy» откажется работать, если порты 80 и 443 занял чужой веб-сервер,
а не станет его перенастраивать.

</details>

<details>
<summary><b>Нужно ли уметь работать в терминале?</b></summary>

<br>

Нет. Нужны только адрес сервера, логин и пароль из письма хостинга. Всё остальное делает приложение
и объясняет простыми словами.

</details>

<details>
<summary><b>Что если я потеряю компьютер с ключом?</b></summary>

<br>

Сервер останется вашим. При установке вы задаёте пароль сервера — им и возвращают доступ с нового
компьютера: приложение обменяет его на новый доступ, ничего не переустанавливая. На сервере этот пароль
хранится только в виде хеша, а подобрать его мешает пауза, которая удлиняется после каждой ошибки.

</details>

<details>
<summary><b>Здесь есть исходный код?</b></summary>

<br>

Нет, это витрина: репозиторий нужен для релизов, обсуждений и сообщений об ошибках.
Код закрыт, но всё, что агент делает с сервером, видно в плане изменений перед применением.

</details>
